TribeMD — área de teste

Somente leitura. Esta área usa o navegador no servidor, sem conectar a coleta à emissão, ao WhatsApp ou à IA.

Use sempre o mesmo identificador para recuperar os cookies dessa clínica. Uma sessão de navegador por vez.

Os campos são apagados após o envio. Perfil e credenciais ficam criptografados no servidor. Nenhuma gravação de sessão é iniciada pelo teste.

Nenhuma sessão aberta.

A imagem atualiza a cada segundo. Campos de entrada são ocultados; a imagem pode conter nomes de pacientes. Clique apenas para concluir uma verificação de login.

Resultado de leitura

Recorte do calendário ou linhas visíveis. Sem acesso ao histórico completo, uma consulta realizada observada não comprova a última consulta do paciente.

A leitura de dados inclui Atendido e Finalizado: nome completo, CPF, contato e valores, quando disponíveis. Valor cobrado não comprova pagamento. Os dados ficam apenas nesta sessão; evite compartilhar o resultado.

Status e sinais de rede, sem corpos, senhas ou valores de cookies.
