Política de Privacidade

O Noto leva a sua privacidade a sério. Esta política descreve como tratamos as suas informações e as informações dos seus pacientes.

1. Coleta de Dados

Coletamos apenas os dados necessários para a prestação do serviço de emissão de notas fiscais, o que inclui informações de cadastro do profissional de saúde e os dados enviados via WhatsApp referentes aos pacientes.

2. Uso dos Dados

Os dados dos pacientes enviados via WhatsApp são utilizados exclusivamente para a geração da Nota Fiscal de Serviço (NFS-e) e para o envio do documento gerado. Não utilizamos os dados dos seus pacientes para nenhuma outra finalidade comercial ou de marketing.

3. Compartilhamento

As informações fiscais são compartilhadas exclusivamente com os órgãos governamentais competentes (prefeituras) para o fim de emissão da nota fiscal, conforme exigido por lei.

4. Uso de Dados de APIs do Google

O uso e a transferência de informações recebidas das APIs do Google para qualquer outro aplicativo pelo Noto seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

O Noto acessa exclusivamente os arquivos de planilhas do Google Drive que o usuário selecionar explicitamente através da interface do Google Picker. Os dados contidos nessas planilhas são lidos apenas para importar o cadastro de pacientes (nome, CPF, e-mail e telefone) para a conta do próprio profissional de saúde, não sendo compartilhados com terceiros nem utilizados para fins publicitários ou treinamento de modelos de inteligência artificial generativa.
